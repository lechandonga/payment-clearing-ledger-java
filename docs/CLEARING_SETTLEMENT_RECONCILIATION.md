# 清算、结算与对账规则

## 1. 金额与精度

- 所有金额一律使用 `long` 表示的**最小货币单位**（如 USD 美分），全程不使用浮点。
- 金额校验只接受正整数（开户期初余额允许 0 或正整数）。
- 不同币种之间**绝不直接相加**：每张凭证只能含单一币种，系统账户按币种隔离
  （`ACQUIRER_PAYABLE:USD` 与 `ACQUIRER_PAYABLE:EUR` 是两个独立账户）。

## 2. 账户体系（每个币种一套系统账户）

| 账户 | 自然余额方向 | 含义 |
| --- | --- | --- |
| `{accountId}` | 借方 | 客户可用余额，永远非负 |
| `{accountId}#HELD` | 贷方（占用额以非负大小记录） | 客户已授权未结算的资金占用 |
| `CLEARING:{ccy}` | 借方 | 授权过渡挂账户，每张凭证内借贷互抵，余额恒为 0 |
| `ACQUIRER_PAYABLE:{ccy}` | 借方 | 已捕获待结算净额：Σ捕获 − Σ退款 − Σ已结算，恒非负 |
| `MERCHANT_ACQUIRED:{ccy}` | 借方 | 商户已结算累计款 |
| `OPENING:{ccy}` | 贷方 | 开户注入资金的对方科目 |

过账时按账户汇总整张凭证的净变动，只检查**最终余额**是否违反账户自然方向
（凭证内部允许系统账户出现有借有贷的中间形态）。一旦最终余额非法，整张凭证不入账。

## 3. 各类业务的复式分录

授权（冻结，金额 a）：

```
借 {acct}#HELD          a   （占用增加）
  贷 CLEARING:{ccy}     a
借 CLEARING:{ccy}       a
  贷 {acct}             a   （可用余额减少）
```

捕获（金额 a）：

```
借 ACQUIRER_PAYABLE:{ccy}  a
  贷 {acct}#HELD           a   （释放占用，资金转为待结算）
```

撤销剩余授权（金额 a）：

```
借 {acct}                  a   （退回可用余额）
  贷 {acct}#HELD           a
```

退款（金额 a，只能退已捕获未退部分）：

```
借 {acct}                       a   （退回客户）
  贷 ACQUIRER_PAYABLE:{ccy}     a   （待结算净额减少）
```

结算批次（金额 = 该币种当前待结算净额 N）：

```
借 MERCHANT_ACQUIRED:{ccy}   N
  贷 ACQUIRER_PAYABLE:{ccy}  N   （待结算清零）
```

开户（期初余额 o）：

```
借 {acct}              o
  贷 OPENING:{ccy}     o
```

每张凭证在构造时强制：同币种、借方合计 = 贷方合计、且合计 > 0。

## 4. 结算批次的恰好一次

- `POST /api/settlements` 按币种触发：把当前 `ACQUIRER_PAYABLE:{ccy}` 余额整批结给商户。
- 相同 `idempotencyKey` 重放：返回同一个 `batchId` 与同一响应，不会再生成凭证。
- 并发触发同一批次：幂等键锁 + 账户锁保证只有一个线程入账，其余线程全部读到首次结果。
- 待结算为 0 时触发：返回 `SETTLEMENT_NOTHING_DUE`（409），不产生空批次凭证。
- 失败路径（校验拒绝/余额非法）在锁内抛出异常，不改动任何账户与单据金额：
  不会多扣可用余额、不会少释放或多释放授权占用。

## 5. 并发控制

`LockManager` 维护全局资源锁命名空间，所有键加统一前缀：

- `I:{操作}:{幂等键}` 幂等键锁
- `P:{支付单号}` 单据锁
- `A:{账户名}` 账户锁（客户可用账户、`#HELD` 占用账户、各币种系统账户）

一次写操作涉及的所有锁键先去重、再按字典序全序加锁、逆序释放，
因此任意两个线程的加锁顺序都是同一个全序，**结构上不可能死锁**。
并发下的冲突由业务校验给出确定结果（超额即 409），不存在“谁后写谁覆盖”的随机结局。

## 6. 对账

- `GET /api/journals`：全部凭证（带序号、业务类型、幂等键、借贷合计）。
- `GET /api/payments/{paymentId}/journals`：单据维度的凭证。
- `GET /api/reconciliation/trial-balance`：按币种、按账户汇总借方/贷方发生额与净额。

对账规则：

1. 每张凭证 `totalDr == totalCr`。
2. 每个币种在试算表中所有账户的借方合计 = 贷方合计。
3. 客户可用余额 + 客户占用额 + 待结算净额 + 已结算商户款（减退款）与资金来源
   （期初/授权）逐币种可核对；跨币种各自平衡，不做汇总相加。
